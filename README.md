# 기업 진단 모바일 PWA

기업명 또는 티커를 입력하면 모바일 화면에서 기업 현황, PER/PBR/ROE/부채비율, 성장 가능성 점수, 섹터 열기, 버블 위험, 스트레스 가격을 보여주는 Next.js PWA입니다.

## 핵심 특징

- 휴대폰 URL 접속 가능
- 홈 화면에 앱처럼 추가 가능한 PWA
- 기업명 → 티커 자동 변환 일부 지원
- 삼성전자, SK하이닉스, 현대차, NAVER, 카카오 등 주요 한국 기업명 지원
- Yahoo Finance 공개 엔드포인트 기반 실시간 조회
- 각 지표별 쉬운 설명 포함

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## Vercel 배포

1. 이 폴더를 GitHub 저장소에 업로드합니다.
2. https://vercel.com 에 로그인합니다.
3. `Add New` → `Project`를 선택합니다.
4. GitHub 저장소를 Import합니다.
5. Framework Preset이 `Next.js`로 잡혀 있는지 확인합니다.
6. Deploy를 누릅니다.
7. 배포가 끝나면 `https://프로젝트명.vercel.app` URL이 생성됩니다.

## 모바일에서 홈 화면 추가

### iPhone Safari

1. 배포 URL 접속
2. 하단 공유 버튼 탭
3. `홈 화면에 추가` 선택
4. 추가 완료

### Android Chrome

1. 배포 URL 접속
2. 주소창 또는 메뉴의 설치 안내 선택
3. `설치` 또는 `홈 화면에 추가` 선택

## 주의사항

- 성장 가능성 %는 미래 수익 확률이 아니라 현재 데이터 기반 점수입니다.
- 버블 붕괴 가격은 예언이 아니라 스트레스 테스트입니다.
- Yahoo Finance 공개 데이터는 지연/누락될 수 있습니다.
- 한국 기업 재무제표는 일부 지표가 비어 있을 수 있습니다. 더 정확한 한국 재무제표가 필요하면 DART Open API 연동을 추가하세요.
